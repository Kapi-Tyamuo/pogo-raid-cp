# レイド捕獲CP検索（Pokémon GO）

レイドで倒したポケモンの**捕獲画面CPの範囲**を、その場ですぐ引くための単体HTMLアプリ。

- `index.html` … これ1枚だけで動く。ネット接続不要。
- `artifact.html` … 同じ中身のArtifact公開用（`<html>`/`<head>` なし）。

## できること

| 機能 | 内容 |
| --- | --- |
| CP範囲 | 最大CP（15/15/15）と最低CP（レイドの個体値下限）、HP範囲 |
| モード切替 | 天候ブースト（Lv20 → Lv25）、シャドウレイド（個体値下限 10 → 6） |
| 個体値の逆引き | 捕獲画面のCP（＋HP）を入力すると、ありうる個体値の組み合わせを列挙 |
| CP早見表 | Lv20 / Lv25 / Lv40 / Lv50 / Lv51（バディ最高ランク）のCP |
| おぼえる技 | 通常技・スペシャル技を威力／エネルギー／時間つきで一覧、レガシー技にバッジ |
| 検索 | 日本語名（ひらがな入力可）・英語名・図鑑番号。全1245種（リージョンフォーム含む） |

一覧は60件ずつ追記していく（表示件数の上限はなし）。下端まで来ると自動で足され、
スクロールイベントが届かない環境でも「残り N 件を表示」ボタンから続きを出せる。

初期表示は伝説・幻・ウルトラビースト（＝レイドボスになりやすい182種）。

### フォームの扱い

元データ（1399件）には、CPを引くうえで区別できない行がかなり混ざっているので `fetch_data.py` で整理している。

- **CPが同じフォームを統合（103件）** — `RAIKOU` / `RAIKOU_S`、アンノーンのA〜Z、メテノの色違いなど。名前・図鑑番号・種族値・タイプがすべて同じものは1件にまとめ、技が最も多く登録されている行を代表にする。
- **テンプレート行を削除（51件）** — `DARMANITAN`（素）と `DARMANITAN_STANDARD`（ノーマルモード）のような重複。種族値・タイプが一致し、かつ技が既定フォーム側にすべて含まれるときだけ素の方を捨てる（メロエッタ・ゲノセクト・ニャオニクスのように技が違う場合は両方残す）。
- **日本語フォーム名の補完** — ヒスイ・パルデアなど、元データが素の名前のままにしているフォームに `FORM_LABEL` で名前を付ける。未登録の接尾辞が出たらビルド時に警告が出る。

## 計算式

```
CP = ⌊ (攻撃+個体値) × √(防御+個体値) × √(HP+個体値) × CPM² ÷ 10 ⌋   （最低10）
HP = ⌊ (HP種族値+個体値) × CPM ⌋                                   （最低10）
```

CPM は `game_master` の `playerLevel.cpMultiplier`（Lv20 = 0.5974、Lv25 = 0.667934）。

ミュウツー 2294–2387 / ブースト 2868–2984、レックウザ 2102–2191、カイオーガ 2260–2351、
最大強化CP（ミュウツー 4724 / レックウザ 4336 / カイオーガ 4652）がゲーム内の値と一致することを確認済み。

## スマホで使う

Safari で `index.html` を開く → 共有ボタン →「ホーム画面に追加」。
アイコンから起動でき、以降はオフラインでも動く。

## データの更新

新しいポケモンや技が追加されたら:

```bash
python3 fetch_data.py   # 公開データを取得して src/godata.json を再生成
python3 build.py        # index.html / artifact.html を再ビルド
```

`--cache` を付けると `.cache/` の既存ダウンロードを使い回す。

## ファイル構成

```
pogo-raid-cp/
├── index.html        # 生成物（配布するのはこれ）
├── artifact.html     # 生成物
├── build.py          # src/body.html + データ → HTML
├── fetch_data.py     # 公開データ → src/godata.json
├── src/
│   ├── body.html     # アプリ本体（HTML/CSS/JS）。__DATA__ にデータが差し込まれる
│   └── godata.json   # 生成物（157KB）
└── .cache/           # ダウンロード済みの元データ（gitignore 対象）
```
